# Guard Bands v0.11.0

This pre-1.0 release makes Guard Bands a cross-language protocol rather than a
Python-only format.

## Highlights

- Protocol v2 uses RFC 8785 JSON Canonicalization Scheme for deterministic
  cross-language signatures.
- Version-specific algorithm tags prevent protocol and algorithm confusion.
- Python continues to verify legacy v1 artifacts during staged migration.
- Deterministic HMAC-SHA256, Ed25519, inline, detached JSON, MCP exchange,
  legacy, and negative conformance vectors are committed and checked in CI.
- The normative wire format and migration sequence are documented in
  `docs/PROTOCOL.md`.
- A compatible TypeScript core and MCP implementation is available at
  https://github.com/Cryptix-Security/guard-bands-ts.
- The proposed remote-signing boundary and the independent-review gate for
  v1.0.0 are now documented.

## Status

Guard Bands remains an experimental, pre-1.0 security mechanism. The
independent protocol/security review is being tracked at
https://github.com/Cryptix-Security/guard-bands/issues/31. This release does not
claim production readiness or that the review has occurred.

Install directly from the tag:

```bash
python -m pip install 'guard-bands @ git+https://github.com/Cryptix-Security/guard-bands.git@v0.11.0'
```
